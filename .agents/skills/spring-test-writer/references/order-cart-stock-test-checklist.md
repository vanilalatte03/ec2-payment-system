# Order Cart Stock Test Checklist

주문, 장바구니, 재고 테스트에서는 결제 전 상태 경계, 재고 선차감 트랜잭션, 장바구니 정리 시점, 소유권 검증을 우선 검증한다.

## 우선순위

1. 장바구니 상품 담기 성공
2. 동일 상품 재담기 시 수량 합산
3. 장바구니 담기 또는 수량 변경 시 재고 초과 차단
4. 주문서 미리보기의 현재가 기준 산정
5. 주문 생성 성공 시 주문, 주문상품, 결제 대기 레코드 동시 생성
6. 주문 생성 시 재고 선차감
7. 일부 상품 재고 부족 시 주문 생성 전체 롤백
8. 주문 생성 시 포인트 잔액 부족 차단
9. 결제대기 주문 취소 시 주문, 결제 상태 변경과 재고 복구
10. 결제 완료 전 장바구니 유지, 결제 완료 후 장바구니 비우기
11. 타인 장바구니 또는 주문 접근 차단

## 장바구니

- 인증된 회원만 장바구니 API를 사용할 수 있는지 검증한다.
- 동일 상품을 다시 담으면 기존 장바구니 항목 수량이 합산되는지 검증한다.
- 상품 담기와 수량 변경에서 요청 수량이 재고를 초과하면 실패하는지 검증한다.
- 장바구니 조회의 상품별 금액과 합계 금액이 현재 상품 가격과 수량 기준으로 계산되는지 검증한다.
- 상품 개별 삭제와 전체 비우기가 본인 장바구니에만 적용되는지 검증한다.

## 주문서 미리보기

- 장바구니 상품 ID 목록이 비어 있으면 장바구니 전체 기준으로 응답하는지 검증한다.
- 장바구니 상품 ID 목록이 있으면 선택된 항목만 응답하는지 검증한다.
- 주문서 미리보기는 주문 스냅샷을 저장하지 않고 현재 상품명, 현재가, 수량, 합계 금액을 반환하는지 검증한다.
- 타인의 장바구니 항목이나 존재하지 않는 항목이 포함되면 실패하는지 검증한다.

## 주문 생성과 재고 선차감

- 주문 생성 시 주문, 주문상품 스냅샷, 결제 대기 레코드가 같은 흐름에서 생성되는지 검증한다.
- 주문상품에는 주문 시점의 상품명과 가격 스냅샷이 저장되는지 검증한다.
- 서버가 주문번호와 `portonePaymentId`를 생성하고 결제 레코드에 저장하는지 검증한다.
- 단일 트랜잭션 안에서 모든 주문 상품의 재고를 검증하고 선차감하는지 검증한다.
- 일부 상품이라도 재고가 부족하면 주문, 결제, 주문상품, 재고 변경이 모두 롤백되는지 검증한다.
- 포인트 사용 금액이 잔액을 초과하면 주문과 재고 변경이 생성되지 않는지 검증한다.
- 주문 생성 시점에는 장바구니가 비워지지 않는지 검증한다.

## 주문 조회와 소유권

- 내 주문 목록은 본인 주문만 최신순으로 조회되는지 검증한다.
- 주문 상세는 주문 정보, 주문상품 스냅샷, 결제 상태, 포인트 사용/적립 요약을 포함하는지 검증한다.
- 타인의 주문 목록, 주문 상세, 주문 취소 요청이 실패하는지 검증한다.
- 주문 생성 이후 주문 수정 또는 삭제가 불가능한 정책을 테스트 대상 API에서 우회할 수 없는지 검증한다.

## 주문 취소와 재고 복구

- 결제대기 상태의 본인 주문만 직접 취소할 수 있는지 검증한다.
- 주문 취소 시 주문 상태는 주문취소, 결제 상태는 실패로 함께 변경되는지 검증한다.
- 주문 취소 시 선차감된 재고가 주문 상품 수량만큼 복구되는지 검증한다.
- 이미 결제 완료된 주문은 주문 취소 API가 아니라 환불 흐름으로만 처리되는지 검증한다.
- 주문 취소 후 장바구니가 유지되어 새 주문 생성으로 재시도할 수 있는지 검증한다.

## 결제 완료와 장바구니 정리 경계

- 결제 완료 전에는 주문 생성이 성공했더라도 장바구니가 유지되는지 검증한다.
- 결제 완료 트랜잭션에서 주문에 사용된 장바구니 항목이 비워지는지 검증한다.
- 결제 실패, 검증 실패, 회원 직접 주문 취소에서는 장바구니가 유지되는지 검증한다.
