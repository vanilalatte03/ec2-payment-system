# 개발용 더미데이터

`src/main/resources/dev-dummy-data.sql`은 필수 기능을 로컬에서 바로 테스트하기 위한 MySQL 더미데이터입니다.

## 실행 방법

애플리케이션 스키마가 생성된 뒤 MySQL에서 직접 실행합니다.

macOS/Linux:

```shell
mysql -h localhost -u YOUR_USER -p YOUR_DATABASE < src/main/resources/dev-dummy-data.sql
```

Windows PowerShell:

```powershell
Get-Content -Raw -Encoding UTF8 src/main/resources/dev-dummy-data.sql | mysql -h localhost -u YOUR_USER -p YOUR_DATABASE
```

`YOUR_USER`, `YOUR_DATABASE`는 로컬 MySQL 계정과 데이터베이스명으로 바꿔 실행합니다.

Spring Boot 시작 시 자동 실행되도록 연결하지 않았습니다. 현재 프로젝트는 테이블 생성 방식이 코드로 완전히 확정된 상태가 아니므로, 개발자가 필요할 때 명시적으로 주입하는 용도입니다.

## 기본 계정

| 용도 | 이메일 | 비밀번호 | 회원 ID |

## 주의 사항

- 더미데이터는 ID `10001`~`19999` 범위를 사용합니다.
- 실행 시 같은 ID 범위의 기존 더미데이터를 삭제한 뒤 다시 삽입합니다.
- 테이블명과 컬럼명은 현재 개발 스키마의 복수형 네이밍을 기준으로 작성했습니다.
- 실제 엔티티 구현에서 컬럼명이 달라지면 이 SQL 파일의 컬럼명만 맞춰주면 됩니다.
- 회원 `10001`의 포인트 잔액 스냅샷은 더미 포인트 원장 합계와 일치합니다. 현재 정책은 음수 포인트 잔액을 허용하지 않으므로 더미 데이터도 0 이상 잔액만 포함합니다.
