# Transaction Convention

트랜잭션은 Service 계층에서 시작한다.
Facade는 외부 API 호출과 내부 트랜잭션 호출 순서를 조율하며, 외부 API 호출을 포함하는 메서드에는 기본적으로 트랜잭션을 열지 않는다.

주의 사항:

- 외부 API 호출과 DB 트랜잭션 범위를 신중하게 잡는다.
- 외부 API 호출 전후로 필요한 DB 작업은 별도 Service 메서드로 나누어 짧게 실행한다.
- 결제 성공 후 내부 처리 실패 가능성을 고려한다.
- 결제/환불은 멱등성을 고려한다.
- 읽기 전용 메서드는 `readOnly = true`를 사용한다.

결제 도메인에서는 다음을 특히 확인한다.

- 결제 확정 중복 처리
- 환불 중복 처리
- Webhook 중복 처리
- 외부 결제 성공 후 내부 실패 시 보상 트랜잭션
